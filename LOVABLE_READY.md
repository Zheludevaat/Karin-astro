# Lovable-ready handoff

This repository has been prepared as a Lovable migration source.

Start with:

1. `lovable/MASTER_PROMPT.md`
2. `lovable/PROJECT_KNOWLEDGE.md`
3. `data/karin-profile.json`
4. `karin-chart.svg`
5. `docs/ASTROLOGY-SOURCE-OF-TRUTH.md`

Then follow `lovable/MIGRATION_CHECKLIST.md`.

The legacy `index.html` remains a visual and behavioral reference. It is not the target architecture.

Because Lovable cannot import an existing GitHub repository directly, create a new Lovable project, use the migration package above, and connect that new Lovable project to GitHub after the rebuild is stable.
